## GitHub Pages

For GitHub Pages:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.
6. Open the generated GitHub Pages URL.

## Contact form

The contact form uses `mailto:`. It opens the visitor's email application with the message prepared; it does not use a server-side form service.
