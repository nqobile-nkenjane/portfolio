# Nqobile Nkenjane — Professional IT Portfolio

A modern personal portfolio for showcasing IT Technical Support, Web Development, certifications, experience and projects.

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `assets/` — CV, certificates and project images

## Before publishing
1. Add your CV as `assets/Nqobile-Nkenjane-CV.pdf`.
2. Add certificate files inside `assets/certificates/`.
3. Replace the placeholder email.
4. Replace the LinkedIn placeholder with your actual profile URL.
5. Replace project `#` links with your real live websites.
